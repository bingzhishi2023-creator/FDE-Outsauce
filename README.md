## 核心设计原则

**机器对、机器查、机器留痕；人确认、人签字、人担责。**

- 智能体只读辅助核对，不写回、不控设备、不出正式结论（f05 / f32 / f40）
- 三个 P0 卡口（版本维护责任人 / 最小可回溯字段集 / 复核闭环）未书面确认不进开发
- 验收标准：50 次交接全部匹配指引版本、未复核异常保留责任人与状态、每条结果关联来源与人工复核记录（f42）

> 数据溯源：全部证据编号（f00–f54）出自 01-访谈备忘录；报告为合成演练产物，需求为待验证假设。
